# 数据与隐私

## 数据存在哪

- 桌面端：应用数据目录下的 SQLite 数据库（Windows 为 `%APPDATA%\com.rdops.task-inspector\task-inspector.db`）；
- 浏览器预览：localStorage，仅用于开发调试；
- 项目对话的消息：localStorage，只存在本机；
- 项目画像、缓存、克隆的代码：设置里的「代码目录」「缓存目录」。

应用不会把数据上传到自己的服务器。

## 哪些内容会发给模型

检查、项目画像、活动报告、项目对话会把以下内容发给配置的模型服务：

- 日报正文、项目名、人员姓名；
- GitLab 提交标题、正文、文件路径和必要的代码片段；
- 项目画像、模块摘要；
- 工具查询结果和命令输出（如果执行了命令）；
- 对话历史（最近若干轮）。

不会发给模型：

- GitLab Token、日报系统密码；
- 完整的环境变量；
- 应用日志。

模型服务由用户在设置里指定，数据是否出境、是否被留存取决于该服务商的策略。

## 日志

- 桌面端调试模式会写日志，记录请求地址、状态码、耗时、模型名、提示词规模；
- 不记录 API Key、密码、日报正文、命令完整输出；
- HTTP 请求体会在包含登录信息时跳过，其它情况截断；
- 发布版默认不写持久日志。

## 命令执行的风险

- 命令以当前用户权限运行，没有沙箱；
- 可以访问本机文件、网络、凭据和子进程；
- cwd 限制只决定起始目录，不能阻止 `cd` 或绝对路径；
- 高风险模式识别只是提示，不能替代人工判断；
- 确认卡片是唯一的安全边界，执行前请逐字检查命令。

## 应用数据操作

对话里的人员/项目写操作：

- 只通过应用现有接口写 SQLite；
- 不执行原始 SQL；
- 不删除成员/项目/关联；
- 不在 GitLab 侧创建组、仓库或用户；
- 写之前会显示字段变更并等待确认。
