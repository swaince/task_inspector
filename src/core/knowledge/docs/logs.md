# 日志同步

日报不是只读数据：员工可以补写、修改，甚至删除。本地库只是某个时刻的快照，所以应用把「同步」做成显式操作。

## 增量同步

- 点击后先选择起止日期，默认最近 30 天；
- 只写入源系统这次返回的日期，不会主动删除本地历史，避免接口分页或临时权限问题造成误删；
- 同步时会和本地逐条比对，列出新增、修改、删除的记录；覆盖这些日期的项目/人员分析历史会被标记为「日志已更新」，可在分析历史里一键重新分析。
- 适合日常使用：重拉最近一个月，员工改过的内容就会更新到本地。

## 全量同步

- 点击后同样选择起止日期，默认最近 30 天；
- 按区间重新拉取，并清空区间内源系统已经不再返回的日期；
- 如果源系统返回 0 条而本地有数据，应用会拒绝清空并提示先检查接口、范围和权限；
- 如果返回条数达到分页上限，同样会拒绝清空，避免只拉到一部分就把其余日期删掉。

## 查看日志

- 「日志」页按日期列出每天的人数、条目数和最近同步时间；
- 点某一天进入中间页，用卡片展示当天每个人的项目数、工时和内容摘要；
- 再点某个人的卡片进入单人详情，可以看到当天申报的全部项目、每个项目的工时、工作内容和任务编号；
- 单人详情右上角可以只强制更新这个人的这一天。

## 更新某人某段时间

- 「日志」页选择人员 + 起止日期，逐天重新拉取这个人的记录；
- 只替换这个人的记录，其他人的日报和同步时间不受影响；
- 某一天需要单独处理时，打开这个人的单日详情，点右上角的「强制更新这一天」，或在项目活动详情页的「当天日报」卡片右上角更新；
- 如果日志中心已经删掉了某天的日志，本地对应记录会被清除，并计入「源系统无记录」。

## 数据口径

- 每条日报记录保存最后一次写入本地库的时间 `syncedAt`，可以在日志页看到；
- 实时拉取只发生在显式同步和单人强制更新时；项目活动、人员活动、项目对话都只读本地已同步的数据，避免频繁请求日志中心；
- 同步只覆盖日报，不影响人员、项目、检查和画像数据。
