# 设置

设置分为七个页签，修改后点右下角「保存」或离开输入框时自动保存。

## GitLab

- **地址**：GitLab 根地址，例如 `https://gitlab.example.com`；
- **Token**：至少需要 `read_api` 权限；检查提交、仓库、用户都依赖它；
- **分组/范围**：限定同步哪些组，减少项目数量；
- **最大项目数**：仓库目录构建的上限，达到上限会截断并提示；
- **跳过 TLS 校验**：只在内网自签名证书时打开。

401 通常是 Token 无效或过期；403 通常是权限不足（缺 `read_api`）；404 通常是路径错误或没有访问权限。

## 日报系统

支持三种来源：

| 来源 | 说明 |
|---|---|
| 接口（http） | 对接内部日报 API，可配置登录、分页、字段映射 |
| 本地导入（csv） | 导入导出的 CSV，适合离线试用 |
| 演示数据 | 内置样例，仅用于熟悉界面 |

接口模式的关键配置：

- 列表接口路径、方法、每页条数、最多页数；
- 请求体模板，支持 `{date}`、`{startDate}`、`{endDate}`、`{page}`、`{limit}`；
- 登录接口和账号密码（只用于换取会话，不保存到日志）；
- 字段映射：成员、项目、工时、内容、日期；
- 成员/项目 ID 的映射表。

接口返回里的 `loginPwd` 等敏感字段不会被映射，也不会出现在界面或日志里。

## 模型

- **服务商**：Anthropic 或 OpenAI 兼容；
- **接口地址**：留空用官方地址，内网网关填自定义地址；
- **模型名**、**API Key**、**温度**、**最大输出**、**超时**；
- 并发数决定检查时同时发多少个模型请求。

模型没配置时，检查仍可运行，但只按「有没有提交」做粗略判断；项目对话不可用。

## 判定规则

- **时间窗**：前一天几点到次日几点算当天；
- **核心时段**：窗口内哪些时段算正常工作时间，窗口外的提交会标记但不排除；
- **判定权重**：一致、部分一致、不一致各自的分数；
- **提示词附加规则**：团队自己的判定口径。

## 代码分析

- **代码目录**：本地 checkout 的根目录，按 `<namespace>/<repo>` 查找；
- **缓存目录**：应用生成的克隆副本、索引和分析产物，可以清空；
- **自动建索引 / 自动克隆**：生成画像时是否自动执行；
- **浅克隆深度**：越大热点越准、克隆越慢；
- **codegraph / graphify 路径**：留空自动从 PATH 查找；
- **Skills**：本地 markdown 文件，生成画像时拼进系统提示；
- **MCP 服务器**：stdio 服务的命令、参数、环境变量、工作目录；
- **命令执行**：允许项目对话提议本机命令；默认关闭，每条命令仍需确认。

## 工作日历

- 导入 ICS 节假日文件，或手动添加放假/补班日期；
- 周末和法定节假日不计入检查分母；
- 日历只影响「是不是工作日」，不影响提交归属的时间窗。

## 数据管理

- 检查历史保留天数；
- 清空检查历史、日报缓存、项目画像等；
- 导出/导入配置（如果当前版本提供）；
- 重置数据前会二次确认，删除不可恢复。
